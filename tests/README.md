# Testing Documentation

This folder contains manual testing documentation and API verification checklists for the Developer Productivity Suite.

These files help verify completed phases before moving on to the next phase. Each phase's checklist documents the expected behavior, the status, and the acceptance criteria for the features built in that phase.

## Files

- [`authentication.md`](./authentication.md) — Authentication-related testing checklists.
- [`api.md`](./api.md) — Table of implemented API endpoints and their status.

## How to Use

1. Start the backend server and ensure MongoDB is connected.
2. Follow the checklist for the phase you are verifying.
3. Mark each item as verified before considering the phase complete.
